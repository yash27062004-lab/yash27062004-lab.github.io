# Personal Website

This is my personal website and technical blog. I'm building it from scratch using Go, HTML, and CSS to learn backend development and create a website of my own.

## About

The website will be a place to share information about me, my projects, and what I learn while working with Go and backend development.

## Features

- Personal homepage and about page
- Technical blog with articles
- Clean and responsive design
- Categories and tags for blog posts
- RSS feed for new articles
- Simple navigation

## Technology Stack

- **Go** — website generator
- **HTML** — page structure
- **CSS** — styling and layout
- **Markdown** — writing blog posts
- **Git and GitHub** — version control and source code
- **GitHub Pages** — free website hosting

## Project Structure

The project is organized into separate folders for Go code, templates, blog content, and static files. This keeps everything easy to understand and maintain.

## How It Works

I write blog posts in Markdown and create the website templates using HTML. A Go program processes the content and generates the website pages, which are then published online.

## Build and Test

The Go generator will build the website from the source files. I will also add tests to check that the content is processed correctly and the pages are generated as expected.

## Deployment

The website will be hosted on GitHub Pages using a free GitHub address. GitHub Actions will automate the build and publishing process.
